# Problems Encountered

## Problem 1 – Requirement Identification

Some requirements were unclear during the initial stage of development.

### Solution
Discussed the requirements with the team and finalized the main system features.

---

## Problem 2 – Database Design

Difficulty was encountered while establishing relationships between members, trainers, attendance and billing tables.

### Solution
Reviewed the database structure and corrected the relationships.

---

## Problem 3 – UI Design

Difficulty was encountered in arranging multiple modules in the application interface.

### Solution
Redesigned the interface and organized the modules into separate screens.

---

## Problem 4 – Database Connection

Errors occurred while connecting the Java application with MySQL.

### Solution
Checked the JDBC URL, database name, username and password and corrected the connection settings.

---

## Problem 5 – Validation

Some invalid input values were accepted by the application.

### Solution
Added input validation and appropriate error messages.
