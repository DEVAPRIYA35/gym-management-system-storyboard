# Gym Management System – Software Engineering Lab Storyboard

## Project Overview

The Gym Management System is a software application developed to manage the activities of a gym efficiently. The system provides features for member management, trainer management, attendance, billing, diet management and fitness progress tracking.

## Objectives

- Manage gym member information
- Manage trainer information
- Assign trainers to members
- Record member attendance
- Manage membership billing
- Provide diet and food information
- Track fitness progress
- Reduce manual work in gym management

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- GitHub
